今天，伊洪大哥[转发](https://t.me/hyi0618/14303)了 [Catoverflow](https://cathy-cai.page/) （注意这不是[本猫](https://about.overflow.cat/)）对一篇博客文章[《亡母二十周年祭》](https://aliengu.com/archives/35701)的[评价](https://t.me/c_res/2316)。读毕，大为震撼，发现博客里面有好多篇当年他已故的母亲的文章。访客还评论说他的文字很有力量，[像是海明威](https://aliengu.com/archives/1230#:~:text=%E6%96%87%E9%A3%8E%E6%8C%BA%E2%80%9C-,%E6%B5%B7%E6%98%8E%E5%A8%81,-%E2%80%9D%E7%9A%84%EF%BC%8C%E7%9C%9F%E8%AF%9A%E3%80%81%E5%B9%B2)，于是我就问
ChatGPT 如何写出像海明威风格的文字。回答大意是少写感受，多写动作，不要用太多描写心理的活动，不要用太多形容词，不要用太多程度副词，最好是通过具体的一个细节来形容，从侧面含蓄地反映出他的心理活动状态；即使作者知道事情的全貌，也只能写十之一二，含蓄而克制（冰山理论）。

这位博主的另一篇文章[失败比成功更重要](https://aliengu.com/archives/35599)也让我很有启发，摘录如下：

{ /** - **尽可能频繁、低成本的去失败，会带给你大量而珍贵的知识储备。久而久之，将迎来毫无疑问的、确定性的、无比稳固的成功。**
> - 太顺利，会让人放松警惕。更进一步，太顺利，实际上剥夺了你了解「真相」的机会。当你一路畅通无阻、却并不清楚「真相」的时候，如盲人骑瞎马，危矣。
> - 成功，不仅只是一个结尾，更应该是一个「必然到来的胜利」。如同玩RTS游戏，开局一条狗，其他全靠一点一点探索战争迷雾，最终心中对胜率大致有个预计。失败，就是不停探路的过程，拼凑自己的世界地图，迎来自己预期中的胜利。 */ }
> 我们应该追求的是知识和经验，而不是一次成功。知识和经验当然会导向成功，但成功本身只是追求知识和经验的副产品、而不是目的。如果失败能带来知识和经验（往往确实如此，而且带来的是价值最高的那部分），那么我们应该勇敢的追求失败，越快、越多、越好。……**主动、快速、频繁的失败，是一个伟大的战略。**如果人人都明白失败带来的东西有多么宝贵，我猜这个世界上很少有人会直奔成功了。幸好大多数人并不喜欢失败，「失败」这个赛道才不至于太卷，追求知识的过程才显得更加有趣。

下午，我弄了杯珍珠奶茶，和一瓶矿泉水，就着吞药。486
讲伊只有这样子才能社会化。但我觉得社会化的主要困难大概是在你在做决定就是启动困难，真正和别人说话之类的时候反而不那么重要，虽然你会磕磕绊绊，听不懂别人说的一些话。我说我上次在群里疯狂聊天，但是现在说话的欲望并不是很多；只是你感觉你脑子里想的东西很美妙，但是实际很难说出来（这是写博客的常态——真是痛苦的感觉）；还很容易受到其他情绪的感染，变得
emotional。[^1]

然后一直开始玩游戏，玩到晚上11点多。就是交替着跳舞机、舞萌和太鼓。大概八九点的时候，我发现我走路不稳，然后这个读谱能力感觉下降了，反正就是那些滑动的
note根本看不过来。我打了好多术曲。然后还有5级的段位认定（图），到最后有点打不过来，如[南十字星](https://maimai.fandom.com/zh/wiki/Southern_Cross)，谱后面这个划来划去的不太行。

我发现我的E舞的店内排名掉到了第3位，我怀疑是我跳了很多新的难曲目，然后这些曲目的准确率不高，所以评级是S
的就比较少，不知道他这个是怎么计算的。我跳了几首四星的曲目，但是排名好像没有变化。我一捉急，就选了第一页一个
7星曲《桃花朵朵开》（图），发现搓地板居然能弄个92%的达成率，弄了个
S，还是挺惊讶的。我好像正在突破无形的瓶颈！但是5星的曲目有的确实很难，比6星、7
星的都难——后者有好多谱子只是速度快，但是踩的步伐并不难；而前者则有很多变态的步伐。我好像始终没有学会这些步法，比如说换脚，经常是左脚一下子踩连续的三个音符。养成习惯就不好了。
