今天，我吃了药，睡眠深沉，头脑恍惚。看着 Telegram 上一堆“不支持的消息”，我的精神更加错乱了。我打开 vibe coding 过后没有更新的文档，又忘了各个设备在子网的 IP 地址了。我找到信创数据库的 PDF 文档，全选复制，粘贴到文本编辑器里，方便复制代码。

![](https://remnote-user-data.s3.amazonaws.com/psAJlXJUQVhn6AjOgGN8FpqMMOvzO1Y5dH8EDZrLjEkcIRLnj71d5xkKJohdQN3bjPp1d6VV1i4rKq3QznTU_S9DfVqmS-U4bVfokSjyYIxu-2fr9eQ_LdUoS2XbGjpU.webp)

我查阅邮箱。我周末提交的 Typst 包裹 tiago 合并到 Universe 里了。我在 Typst 的 Discord 的 showcase [发了个贴](https://discord.com/channels/1054443721975922748/1488825740169576498)。群友称，MoonBit + Typst，是“强强联合💪”。tailscale 的两条 issue 里 mention 到了我，一看原来是鸿蒙支持的 issue。

> bradfitz left a comment ([tailscale/tailscale#12728](https://github.com/tailscale/tailscale/issues/12728#issuecomment-4163026574)) 
>
> Comment from @OverflowCat on dup #18207 (comment)
> > Is there a version of HarmonyOS that we can run in CI that we can build against?
>
> > OpenHarmony provides a QEMU version:
> [https://gitcode.com/openharmony/device_qemu/blob/master/README.md](https://gitcode.com/openharmony/device_qemu/blob/master/README.md)
> >
> > IMO the largest problem is the [lack of Golang support](https://github.com/golang/go/issues/67829), although there are some [successful attempts](https://github.com/siyuan-note/siyuan/issues/13184#issuecomment-2485190822). Huawei has a [fork](https://gitcode.com/openharmony-sig/ohos_golang_go/wiki/Home.md), but I doubt if it is working. I tried to compile a hello world binary, but it does not run on my HarmonyOS laptop.
>

我想，难得有愿意适配的项目，结果 OpenHarmony 什么 SIG 的 Golang port 不给力。 

夜晚，我踩箭头，打六边形拍拍机。我安装了适用于 Linux 的 #HarmonyOS 子系统，名字叫做“融合开发引擎”。我不知道欧拉的包管理器是什么。
