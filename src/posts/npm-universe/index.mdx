众所周知，[Typst Universe](https://typst.app/universe/) 是 typst 生态中的三方包 registry。在 2025 年的年中，向大家介绍新一代的 typst 包管理和三方包仓库：NPM Universe。顾名思义，就是使用一个名叫「npm」的命令行工具的 Typst Universe 替代品。

NPM Universe 如此重要，甚至被许多运行时捆绑。例如，在你的包管理器上安装 `nodejs`，即可获取一份 `npm` 的副本。

```sh
pacman -S nodejs # Arch Linux
brew install nodejs # macOS
scoop install nodejs # Windows

npm -v
10.9.2
```

当然，只有一种实现的标准并不健康。你也可以使用速度更快的 `pnpm` 作为替代品：

```sh
pacman -S pnpm # Arch Linux
brew install pnpm # macOS
scoop install pnpm # Windows
npm install -g pnpm # Already installed npm

pnpm -v
10.11.0
```

与以往的简约风格不同，我们开创性地引入了项目的概念，这有助于我们确定我们的 typst 文稿的依赖版本，以及定义常用的配置。执行下面的命令后，会在当前目录生成一个 `package.json` 文件。

```bash
npm init
```

NPM Universe 和 Typst Universe 一样，提供了一个 社区仓库的入口，用户可以在[这里](https://www.npmjs.com/search?q=keywords:typst
)检索和查阅。

![](https://remnote-user-data.s3.amazonaws.com/Lt0I9QM7FpurdpkOPnWNNMhR0T8Taw2P8Q2pXEBJihWoafxvRf2ifAdR0oLnphveRO3xYbuWnVU4ZXuBXotFCO62XyK22BCwLFRgWzw6rQTALCs31gDJCXY1IyV6BrbI.png)

为了维护各个依赖的版本信息，现在我们不再需要记住特定的版本号，而是直接使用 `npm install{:js}` 就可以安装最新版本了。比如，你可以安装我写的 [`sigfig`](https://github.com/OverflowCat/sigfig) 包来处理不确定度。

```bash
npm install typst-sigfig
```

与导入 Typst Universe 的 `@preview` 类似，我们还需要一个特定的前缀：`node_modules`。这是 NPM Universe 开创性的「节点模块」架构，每个 typst 包是一个单独的文件夹。

```typ
// Pre
// #import "@preview/sigfig:0.1.0": *

// Post
#import "node_modules/typst-sigfig/sigfig.typ": *
```

之所以叫作 Universe，实际上是因为这个包管理器将 typst 包存储在 ``node_modules`` 中。互联网上流传了这样一张图片，说明了 typst 生态的繁荣：

![](https://remnote-user-data.s3.amazonaws.com/XQ4c7szZ4yv-EbP4E-HDfrp329DIRWtAadkZs7m2k6e3S6E5N2xS7CBA8s-k0zzCgNrH3tpoyyOI9lyzcoCLMciwh5FUgn9T2Ns_aYpukyvBv10nZRYefyG67iozLCEN.png)

此外，NPM Universe 无需经过繁琐的审核流程，`init` 好之后，几分钟内即可上传你的代码：

```bash
npm publish # 初次使用需要注册账号
```

NPM Universe 还支持命名空间，这意味着当 typst 升级时，你可以自己将 fork 发版，不必苦苦等待作者适配发版，或者让删掉 `styles` 的库源码污染你的 git 历史。

更棒的是，NPM Universe 甚至还支持查看 typst 包的源码，还提供完善的代码高亮。这是上一代 Typst Universe 都没做到的功能！

![astro-typst 的源码](https://remnote-user-data.s3.amazonaws.com/RFvHAWGCUiKMPJ7Aygljgmlfgt3t4eQeR9ihY-Ynf0wqOf3NsN8voQVQJPwXM4rf-XuQEusmeYVaQpxdxxE2Z9shMmyW0rmdXe1FtvhBIhxEmerWNNA6dubifyGk-ESE.png)

如果你稍加设置，甚至可以在 README 中展示 typst 片段的渲染结果！

```json title="package.json"
{
  ...,
  "scripts": {
    ...,
    "pub": "typst compile --features html --format html README.typ README.md && npm publish"
  }
}
```

当然，NPM Universe 不仅改善了 typst 生态的体验，还意外惠及了前端生态。NPM Universe
慷慨地允许前端开发者分享 Typst 的技术红利——如果你也在使用 [astro-typst](https://github.com/OverflowCat/astro-typst)，可以直接在
``.astro`` 或 ``.mdx`` 文件中导入来自 NPM Universe 的包。就以 astro-typst 中的示例来说：

```jsx
import Simple from "node_modules/astro-typst/src/pages/simp.typ?svg"

<Simple />
```
